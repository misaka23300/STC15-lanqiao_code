# STC15 蓝桥杯单片机代码库

本项目包含蓝桥杯单片机比赛相关的学习代码、模块实例和参考项目，基于 STC15 / STC32G 系列单片机开发。

## 目录结构

- `实例/` — 综合实例代码
- `模块/` — 各硬件模块的独立驱动与演示
- `底层库/` — 常用芯片底层驱动（DS1302、IIC、OneWire 等）
- `教程/` — 入门教程代码
- `参考项目/` — 收集整理的参考代码
