# STC15 蓝桥杯代码库

![License: GPL-3.0](https://img.shields.io/badge/License-GPLv3-blue.svg)

## 项目简介

这是一个用于 STC15 系列单片机的蓝桥杯竞赛代码库，包含了各种示例代码、教程和参考项目。

## 目录结构

- `教程/` - 包含教程相关的代码
- `实例/` - 包含各种实例代码
- `参考项目/` - 包含参考项目代码
- `STC32G_FreeRTOS/` - 包含 STC32G 的 FreeRTOS 相关代码

## 许可证

本项目采用 GPL-3.0 许可证，详见 LICENSE 文件。

## 使用说明

1. 克隆本仓库到本地
2. 使用 Keil C51 或 SDCC 编译器打开对应的项目文件
3. 根据需要修改代码
4. 编译并烧录到 STC15 单片机
